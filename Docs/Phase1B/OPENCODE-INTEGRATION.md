# OpenCode — disabled optional infrastructure

19 October 2026 · Proposal-only architecture adopted. **OpenCode execution is disabled** and is not a prerequisite for1B.2B–1B.5. No invocation, launcher, live session, tool, plugin, provider gateway or runtime configuration activation is authorized.

Phase1B.1 remains intact: native Swift fixture HTTP/SSE components, runtime identities/correlation, reject-only permissions, bounded actor sessions, inert launch manifest, tests and pinned1.18.25 public source/schema. See [protocol](PHASE1B1-PROTOCOL.md), [completion](PHASE1B1-COMPLETION.md) and [checkpoint](PHASE1B1-CHECKPOINT.md). Static schema provenance is not installed-binary execution/conformance or safe configuration evidence. In particular `/permission/{requestID}/reply` is the captured rejection route; the older session route differs and is deprecated. Original rolling-document research is historical in Git, not the authoritative current wire contract.

The original preference for an isolated OpenCode HTTP/SSE worker and OpenCode-to-Ollama gateway is superseded by direct WF-owned ModelProvider inference returning strict CodingProposal data. No JS SDK/bridge, ACP adapter, runtime launcher, tool dispatcher, config compatibility shim or gateway implementation is needed for this delivery path. Preserve existing components for fixture regression and optional future evaluation; do not delete or repurpose them into an implicit live client.

The tested App Sandbox helper enforced outside-container restrictions but did not meet the complete general-purpose execution requirements. No blanket assertion about all native XPC designs or App Sandbox insecurity follows. See [ADR](ADR-EXECUTION-CONTAINMENT.md) and [evidence](PHASE1B2A-SECURITY-FEASIBILITY.md). Source configuration isolation, plugins/MCP/LSP/hooks, inherited descriptors, network and all-owned-resource termination remain unverified for OpenCode. A future reconsideration needs a new explicit decision, separately scoped authorization and real containment/conformance/resource evidence; merely passing fixture tests never enables it.
